# Contributing Guidelines

Thank you for your interest in contributing to **GitMon**!

## How to Contribute
- **Bug reports**: Open an issue describing the problem and steps to reproduce.
- **Feature requests**: Propose new ideas via an issue. Please explain the motivation.
- **Pull requests**:
  1. Fork the repository.
  2. Create a new branch for your change.
  3. Ensure the extension continues to work (run the QA script if applicable).
  4. Keep changes limited to documentation, non‑functional improvements, or bug fixes that do not alter the core mapping logic.
  5. Submit the PR with a clear description of what was changed and why.

## Code Style
- Use **ES6** syntax.
- Follow the existing code formatting (2‑space indentation, semicolons).
- Do not modify `content.js` logic, contribution thresholds, or asset files.

## Testing
- Run the provided QA scripts in `qa/` to verify functionality.
- Ensure the extension builds and loads without errors.
